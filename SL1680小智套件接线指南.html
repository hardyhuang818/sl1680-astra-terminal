⚠️ 接线三铁律：① 全程断电接线，接完检查再上电；② 麦克风 VDD 只能接 3.3V（接 5V 直接烧）；③ 每根线接完后沿线捋一遍，确认没插错排。

四 · 上电验证（接完喇叭后跑）

# 1. 喇叭出声测试（440Hz 嘟一声）
speaker-test -D plughw:CARD=dolphinasoc,DEV=0 -c 2 -t sine -f 440 -l 1

# 2. 没声按序排查
#   a. 换 32bit 帧格式:
aplay -D plughw:CARD=dolphinasoc,DEV=0 -f S32_LE -r 48000 -c 2 /usr/share/sounds/alsa/Front_Center.wav
#   b. 万用表量 HT517 的 Vin-GND 是否 5V
#   c. 检查 EN 是否确实接到了 Vin（这是官方明确要求的短接）
#   d. 三根信号线是否插到 38/35/40（数排最容易错）

# 3. 出声后叫 Claude：切 astra-xiaozhi 输出到板载喇叭 + 加 softvol 音量控制

接线口诀：功放六线＝电源二（Vin→2、GND→6）＋短接二（EN→Vin、GAIN→GND）＋信号三（DI0→38、DI1→35、DI2→40，全在排针末端）。麦克风六线＝电源三（VDD→1、GND→9、L/R→GND）＋信号三（SCK→11、WS→13、SD→15，连续三个奇数脚）。
