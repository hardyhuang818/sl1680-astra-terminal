四 · 今日坑清单（16 连，复用价值最高）实测

  1. 假 35B：@q8_0 实为 Qwen3-4B NSFW 微调+不匹配 mmproj（必崩）；@q3_k_m 才是真 35B-A3B。model_name 必须带量化后缀
  2. 服务端 0.9.5 双 system bug：增强提示词拆两条 system → LM Studio 严格模板 400（"第一轮必成之后必挂"）。修：prompt_template 指向不存在的文件（空串会回落默认）
  3. lms load 必限 --context-length；--gpu max 对超显存文件必 OOM
  4. Sec-WebSocket-Key 解码必须恰 16 字节，否则 400
  5. 下行采样率跟服务端 hello 走（本次 16000，别硬编码 24k）
  6. 板子 SFTP 子系统坏 → PC 起 http.server 板上 wget 拉是最稳部署
  7. busybox 四连：无 timeout、head -c 不支持、nc 无 -w、wget -T 管不住 connect 挂起（探活必须 curl -m）
  8. glibc signal() 默认 SA_RESTART：信号处理必须 sigaction；EINTR 分支查退出标志，否则 SIGTERM 拖 90s 还把对端服务搞成 failed
  9. SSH 单行 $(pgrep -f xxx) 匹配到外层 shell → 用 systemctl show -p MainPID
  10. MCP 时序竞态：tools/list 应答之后再提问，否则 LLM 无工具可用会瞎编
  11. 工具输出单位写死（"446/3959MB"会被复述成"446GB"）
  12. 工具名只用 [a-zA-Z0-9_]（服务端 sanitize 换点号）
  13. dl_face 全词比对状态（listening/thinking/speaking/paused），缩写不认——字幕不显示的真因
  14. dl_face 交叉编译：gst 头在 gst-plugins-base 自己的 image/；传递依赖用 -Wl,--allow-shlib-undefined
  15. Git Bash 改写 /tmp 参数、拆坏 wsl 传参 → 一律 PowerShell + 脚本文件
  16. 环境音误触发：房间有视频声助手会连续对话（还接了粤语）——KWS/门限是产品化必做
