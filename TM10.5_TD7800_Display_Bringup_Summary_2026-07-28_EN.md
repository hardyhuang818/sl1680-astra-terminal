# TM10.5-TD7800 LVDS Panel Bring-up Summary (Display + Touch)

Date: 2026-07-28 | Platform: Synaptics SL1680 (dolphin RDK) | Result: **Display + touch chains fully working; survives power cycle (9/9 self-check items pass)**

---

## 1. Final Signal Chain

```
SL1680 J208 (MIPI-DSI 4-lane, 522.4Mbps/lane)
   → FPC → LAMTL adapter board (Toshiba TC358775, DSI→LVDS)
   → single-link LVDS, 5 differential pairs (OD port / first link, 457Mbps/pair)
   → TM10.5 panel U4 port A → TD7800 TDDI → 1280×720@60 glass

Touch: TD7800 → TP I2C 0x2C (TW0 bus, J32.3/5) + ATTN interrupt (J32.12 = porta line 10)
       → synaptics_tcm2 driver → /dev/input/event2 (2-finger multitouch, ~120Hz)
SPI debug: TD7800 display register port (U5.1/2/3/4 ↔ J32.23/19/21/24) → /dev/spidev0.0
```

## 3. Six Root Causes (in order of discovery)

| # | Root cause | Symptom | Fix |
|---|---|---|---|
| 1 | Base device tree's dsi_panel was the **Raspberry Pi 7" panel config** (800×480/1-lane, power-supply pointing at a physically absent i2c 0x45 chip) | DSI-1 permanently disconnected, SoC never streams | Replace node with TM10.5 timing, drop RPi references |
| 2 | **TC358775 powers up with LVDS outputs tri-stated**; nobody writes its registers | No LVDS output even with DSI running | Bake 29-command init sequence (DSI generic long writes) into DTB |
| 3 | **Panel RESX (U5.9 RST TFT) left floating** | Entire TD7800 held in reset: touch missing + black screen + SPI silent (three symptoms, one cause) | Tie high to 3.3V (hardware) |
| 4 | **U-Boot muxes SM_SPI2_SDO/SDI to UART2 flow control** | SPI reads/writes all zeros; debug channel dead | Add pinmux node in dts to reclaim spi2 function |
| 5 | **Zero bandwidth margin DSI→LVDS** | Full-screen live random color noise (stable raster) | Byte_clk 48975→65300 (+33%), LVCFG PCLKDIV 3→4 |
| 6 | Touch INT bank ambiguous (GPIO10 exists as line 10 on three gpiochips) | Cannot write the interrupt node | Empirical method: ATTN latches low → drain reports over I2C → the GPIO that releases high is the one (gpio586 = porta10) |

**Layer 5 in detail** (the most subtle one): the DSI link carries protocol overhead (packet headers, EoTp, LP transitions). Configuring the DSI input bandwidth exactly equal to the LVDS output bandwidth guarantees the effective pixel rate falls below panel consumption → the bridge line buffer underruns every line → live noise. Control experiment: RK3568 native LVDS through the same jumper wires worked fine, ruling out the cabling. Formula: **LVDS pixel clock = DSI clock-lane frequency (byteclk×4) ÷ PCLKDIV; the DSI link must keep significant bandwidth margin** (vendor example 4.4%, this project 33%).

Four change blocks:

1. **Full replacement of the `dsi_panel` node under `&drm`**:
   - Timing: 1280×720@60, pclk 65300 kHz, H front/sync/back = 97/30/60, V = 7/2/14 (HTOTAL 1467 / VTOTAL 743)
   - `Lanes=4`, `Byte_clk=65300` (⚠️ never lower back to 48975 — full-screen noise)
   - Removed `power-supply`/`backlight` (pointed at the absent RPi chip)
   - `command` = TC358775 init sequence; format `0x29 <len> <reg LE16> <data LE32>`, delay `0xFF <µs LE32>`. Key values: LANEENABLE=0x1F (4 lanes), VPCTRL=0x03F00100, HTIM1=0x003C001E, HTIM2=0x00610500, VTIM1=0x000E0002, VTIM2=0x000702D0, seven LVMX writes = VESA mapping, **LVCFG=0x41** (LVEN + PCLKDIV=4, single link)
   - Commands are auto-sent by the VPP display firmware over the DSI link in LP mode at every modeset (no I2C needed)
2. **New `synaptics_tcm@2c` under `&i2c0`** (touch): compatible `synaptics,tcm-i2c`, INT=`<&porta 10 0x2008>` (= J32.12, pad I2S2_DI1); **deliberately no reset-gpio** (a TDDI reset would kill the display too)
3. **`&spi0` enabled + spidev child** (SM SPI2 → J32.19/21/23/24, TD7800 display SPI debug channel)
4. **New `spi2_data_pmux` under `&sm_pinctrl`**: reclaims SM_SPI2_SDO/SDI from U-Boot's uart2 assignment

## 5. Hardware Wiring Decisions

**Power / control (LAMTL side)**:
- VCC1V8_LCM (J1-8): external **1.8V**; ⚠️ TC358_RST/TC358_PWR_EN must use **1.8V levels** — 3.3V back-feeds through the RESX ESD diode and lifts the 1.8V rail to 2.38V (measured)
- 12V backlight external; 3.3V from J208.1 (PWR_3V3_CTL); enable J208.6 (PWR_ON_DSI) → J1-13
- **Panel U5.9 (RST TFT/RESX) tied high to 3.3V** — floating = whole TD7800 in reset (bug #1)

**LVDS data (LAMTL J3 OD port → panel U4 port A)**:

| LAMTL J3 | Signal | Panel U4 | Signal |
|---|---|---|---|
| 7 / 8 | OD0− / OD0+ | 18 / 19 | LVD0A− / LVD0A+ |
| 9 / 10 | OD1− / OD1+ | 21 / 22 | LVD1A− / LVD1A+ |
| 11 / 12 | OD2− / OD2+ | 24 / 25 | LVD2A− / LVD2A+ |
| 15 / 16 | ODCK− / ODCK+ (clock) | 27 / 28 | LVDCLKA− / LVDCLKA+ |
| 17 / 18 | OD3− / OD3+ | 30 / 31 | LVD3A− / LVD3A+ |

(Single link uses the first link = OD group, confirmed by TC358775 datasheet Fig 5-10; ED group / panel port B entirely unconnected; multiple common grounds)

**Touch + SPI (J32 header)**: TP SCL→J32.5, SDA→J32.3, INT→J32.12, GND→J32.9; SPI SCK→J32.23, MOSI→J32.19, MISO→J32.21, CS→J32.24 ↔ panel U5 pins 1/2/3/4.
