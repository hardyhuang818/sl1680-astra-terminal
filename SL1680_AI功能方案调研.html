⚙️ 先认清 SL1680 能力边界

核心原则：什么在端侧跑，什么必须离线/云端。

✅ 端侧能跑：人物检测/追踪、接近检测、唤醒词、离线 ASR、离线 TTS（含播放克隆音）、播放预渲染 avatar。

⚠️ 必须离线/云：声音克隆的"训练"、3D avatar 的"生成"、大模型对话 —— 要 GPU；SL1680 只负责推理/播放。

出厂自带 AI 资产（这次 build 已含）：预装 YOLOv8 检测模型、Syna AI Player（物体/人脸检测+姿态估计 GStreamer）、官方 synaptics-synap/examples。→ 功能①几乎现成。

🔄 二轮调研：3 个重要优化（补遗）

优化 A：Duix-Mobile — 数字人可能不需要边缘服务器了 ⭐重大

硅基智能开源、全球首个开源 2D 真人级实时数字人：官方标称 4核CPU + 4GB 内存流畅运行、端侧无云依赖、延迟 <1.5s。SL1680 恰好 = 4核 A73@2.1G + 4GB，规格踩线。
落地路径做法风险/工作量
a. 移植核心推理是 C++，移植到 Yocto Linux + GStreamer/DRM 显示中等；先在 PC Linux 验证
b. 分体 ⭐稳SL1680 做传感/语音/逻辑中枢；显示端加一台 ¥200-400 Android 盒跑 Duix，局域网通信零移植风险，快速落地

→ 功能⑤结论修正：实时口型有端侧方案候选，三期优先评估 Duix-Mobile（SDK 主打 Android/iOS，这是唯一限制）。

优化 B：中文声音克隆首选改为 CosyVoice 2（阿里开源）

3 秒克隆9 语种 + 18 中文方言情感标签双向流式合成(首包快)

→ 功能③推荐顺序更新：中文场景 CosyVoice 2 > GPT-SoVITS > OpenVoice；端侧运行时仍 sherpa-onnx/Piper；训练/重推理仍在 PC/云。

优化 C：复用已有成果

本项目已点亮的 HDMI 输出（LT9611）可直接驱动幻影金字塔/HDMI全息风扇/透明OLED——显示链路零新增开发；已集成的触摸屏可做数字人交互面板。

🛒 光影硬件：接口详解 + 采购渠道

1. 全息风扇 — 接口分两类，买前必须确认！

类型接口/工作方式价位能否实时数字人
普通款(WiFi/SD卡)手机 App 经 WiFi 上传 MP4/GIF 文件循环播放；部分支持局域网 API 推送42-65cm ¥100-800❌ 不能实时；SL1680 生成视频→推送，适合固定欢迎动画
HDMI 实时款 ⭐HDMI → 专用控制盒 → 光纤 → 风扇，实时取流；可多台拼接65cm ¥2000+；100-180cm 数千-万元✅ SL1680 HDMI 直出实时数字人

采购：淘宝/京东搜 “全息风扇 HDMI”“3D全息广告机”；1688/Alibaba 厂家 HDFocus、Missyou、GIWOX、衍视。内容要求黑底 MP4（黑=透明悬浮）。提醒：风扇分辨率低、近看颗粒感、有风噪，适合远观/橱窗。

2. 幻影成像金字塔 — 最便宜、无特殊接口 ⭐一期/二期首选

原理就是"普通显示屏平放 + 亚克力四棱锥反射"（Pepper's Ghost）——没有任何特殊接口，SL1680 已点亮的 HDMI/DSI 屏直接用，零新增硬件开发。内容：黑底 + 单面（或四面对称）人物视图。
采购（淘宝关键词）价位
“全息金字塔 展示柜” 桌面 DIY 款（亚克力锥+支架，屏自备=SL1680 的屏）¥50-300
“幻影成像柜”“全息展示柜 180度/360度” 成品柜(含 19-32寸屏)——选 180°单面最适合数字人正面形象¥1000-5000

3. 透明屏（商用高端）

类型接口价位说明
透明 OLED（LG 55" 面板一体机）HDMI/USB万元级自发光 ~45% 透光，数字人"站在玻璃里"效果最佳
透明 LCD 展示柜HDMI¥3000-8000需柜体背光，性价比高

淘宝搜“透明OLED屏 55寸”/“透明液晶展示柜”；厂家：起鸿科技、共显盛视等。SL1680 HDMI 直驱当普通显示器。

4. 空气成像板（DCT/负折射，前沿）

画面悬浮空中可交互；接口同样=接普通屏（屏+成像板组合）。淘宝“空气成像 模组”¥2000-8000；视角窄偏贵，三期再看。

接口一句话结论：除“普通款全息风扇”（WiFi 推 MP4）外，所有光影硬件对 SL1680 来说都是一块 HDMI 显示器——已点亮的 HDMI 链路直接可用。

★ 功能① 人物追踪：AI-Zone 三部曲 = 现成落地流程

# ① 跑板上预装模型(固件自带 /usr/share/synap/models/)
adb push img.jpg /home/root/ ; adb shell
synap_cli_od img.jpg     # YOLOv8 pose → 62ms, 输出 置信度+class(0=人)+坐标+关键点
# ② 导入自己模型 + 一条命令编到 NPU
synap convert --model x.onnx --target sl1680 --out-dir out   # → model.synap → adb push → synap_cli (2-3ms)
# ③ 混合量化: Netron 看结构 → meta.yaml: backbone INT8 + head INT16 (又快又准)

功能①从"基本现成"升级为"官方有逐命令 tutorial"，直接抄。

★ 功能②③⑤ 语音/数字人：Moonshine + Gemma + RAG（官方端侧方案）

麦克风 → VAD(按句间隙切分) → Moonshine ASR(跑 ARM,迁 NPU/Torq)
   → Gemma 270M 小LLM + RAG(喂设备手册防幻觉) → 文本/语音输出

比之前通用方案更优：Synaptics 官方选型、已在 SL 跑通、端侧离线低资源。RAG 是关键——小模型单用会幻觉，喂"手册/欢迎语脚本"后做固定应答足够可靠，正合"欢迎回家 + 简单对话"。映射：② 欢迎语、③ 换克隆音、⑤ 加口型+光影。

功能② 接近检测：多一个选项 —— WiFi Sensing

4612 等模块支持 WiFi Sensing（WiFi 信号感知人存在/移动，无需额外传感器）。若产品本就有 Synaptics WiFi 模块，可省掉毫米波；"有人进房间"级别够用（精度不如毫米波精细）。

面向未来：Torq（Transformer NPU）& 备选 SL2610

Torq = 下一代基于 Transformer 的 NPU（就是我们 build 里的 torq-runtime/compiler），专为端侧 LLM/语音。现阶段 SL1680 的 8 TOPS 够用；要更强端侧对话再看 Torq。SL2610：若产品重心是语音家电（不要视觉/光影），M52 可当纯 MCU 省成本 + 功能安全 + SR80 远场语音前端，是更低成本选择。

结论更新：Duix-Mobile(端侧数字人) + Moonshine/Gemma(端侧语音) + Torq(端侧 LLM 趋势) → "会说话数字人"越来越可能纯端侧/轻边缘完成，不一定要重云服务器。
