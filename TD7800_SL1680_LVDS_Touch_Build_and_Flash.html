3 · 显示架构 & 1280×720 时序

[SoC MIPI-DSI 4-lane]→[MIPI转LVDS 转接板]→[TD7800 LVDS panel 1280×720]

5 · ★ 关键：TDDI 的 TP_RESET（沿用 RK3568 教训）

TD7800 是 TDDI（触摸+显示同一颗芯片）。TP_RESET 复位整颗芯片含显示驱动 IC → 若触摸驱动持有 TP_RESET（active-low），显示初始化时被拉低 → 屏黑。

规则：TP_RESET 必须上电即拉高并保持（硬件上拉，或 DTS gpio-hog）。因此触摸节点不给 reset-gpio；复位后恢复交给驱动内 ENABLE_HELPER。

9 · 烧录 eMMC（3 种方式，来自 Synaptics Confluence）

关键 jumper/按键：SD_BOOT 接上=U-Boot/SD 启动（方式二/三）、断开=eMMC 启动（方式一）；USB_BOOT+RESET 进 USB Boot；UART 115200 8N1，登录 root 无密码。

方式一：USB Boot（★推荐，PC 直连）

  1. 1下载 usb-tool（含 astra-update）
  2. 2Windows 装 WinUSB 驱动：右键 SYNA_WinUSB.inf → 安装
  3. 3USB-C 接 PC ↔ SL1680 的 USB 2.0 口（靠网口那个）；确认 SD_BOOT 断开
  4. 4SYNAIMG/ 改名 eMMCimg 放进 usb-tool 目录，运行 update_emmc
  5. 5按住 USB_BOOT + 点一下 RESET 进 USB Boot 模式 → 自动烧录 → 重启

方式二：U 盘（U-Boot usb2emmc）

FAT32 U 盘拷 eMMCimg/ → 接 UART → 接 SD_BOOT jumper 上电进 U-Boot → usb2emmc eMMCimg → 移除 jumper → reset

方式三：TFTP（U-Boot tftp2emmc）

PC IP 设 10.10.10.2 开 TFTP → 接 jumper 进 U-Boot → setenv ipaddr 10.10.10.10 → tftp2emmc 10.10.10.2:eMMCimg → 移除 jumper → reset
