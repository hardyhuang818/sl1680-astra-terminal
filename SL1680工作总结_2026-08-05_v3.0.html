0. 一句话

TM10.5-TD7800 触摸屏从"显示器"变成了"控制台" —— PC/手机浏览器与触摸屏共用同一套 Web 控制台，可开关服务、调音量、试说 TTS、控舵机（含转速）、看电源轨与对话流； 断电重启八项复验全绿，全自动恢复。

2. 控制台能做什么

  • 功能开关：语音 / 视觉唤醒 / 多屏表情 / 定时提醒 / 时钟屏（dl-face↔dl-clock 互斥服务端强制）+ 重启显示服务、面板 29h 唤醒
  • 语音：音量滑块（实测 15%/85% 听感 A/B 确认闭环）、麦增益（>60% 削顶标红）、TTS 试说、触发欢迎语
  • 舵机：CH0/CH1 角度滑块 + 转速滑块（最右=全速直达）+ 演示摆动 + 常驻红色急停
  • 视觉：摄像头快照（2s 刷新）+ 实时检测框高（调阈值的标定尺）
  • 仪表盘：INA3221 电源轨电压/电流、CPU/内存/磁盘/uptime、触摸中断、设备在位、实时对话流
  • 特意不做：重启按钮（本板软复位不可靠）、任意命令执行（全白名单）

访问方式：TD7800 屏直接触摸 ｜ 手机连 BE3600 WiFi 开 192.168.8.186:8080 ｜ PC 在外 ssh -N -L 18080:192.168.8.186:8080 root@192.168.5.1 后开 localhost:18080

3. 今天修掉的七个问题

# 症状 根因 修法
1 舵机不动 断电后 PCA9685 默认 SLEEP，寄存器能写 PWM 不出 写输出前自动唤醒
2 唤醒了还不动 EXTCLK 粘滞位意外置 1，振荡器停转（datasheet：只有断电或 SWRST 能清） 自动 General-Call SWRST（0x00 发 0x06）再初始化
3 音量拖到 54% 跳回 34% WPE 触摸拖动不触发 onchange（值从未提交）+ 防覆盖保护 window[id+"Touched"] 写 / let 变量读是两个绑定（保护从未生效） 滑块改 input+350ms 防抖提交；统一 TOUCH 对象
4 摄像头快照裂图 路由用全等匹配，?t= 防缓存参数一来 100% 404；且 cp 非原子可能读到半张 JPEG 剥查询串再路由；JPEG 头尾校验+缓存回退；前端预加载成功才换图
5 C920 开机枚举失败(-71) 电气层握手失败（老毛病），远程 hub 复位无效 用户换口重插恢复；顺带修掉 vision_wake 兜底 video3 假跑（改为明确退出+自动重试，插回即自愈）
6 "依赖齐"误判两轮 板上没有 ldd，grep 对空输出全过 LD_TRACE_LOADED_OBJECTS=1 直调 ld.so，一轮收敛（libwpe→atk 等 12 个→gstfft）
7 渐移期间 MODE1 偶发读歪 状态探针与舵机写并发抢 I2C 寄存器指针 渐移期间跳过探针

4. 新增能力：舵机转速

180° 位置舵机没有硬件转速（脉宽只命令位置）。实现软件匀速渐移：

python3 pca9685.py move 0 135 30    # CH0 以 30°/s 走到 135°

当前角度从 OFF 寄存器回读（免记状态）；实测 40°/s 命令，寄存器采样斜率 10°→37°→64°→93°→121°→149° 完全吻合。UI 转速滑块 10~180°/s，最右挡=立即。

5. 沉淀的经验（已录 VERSION / 备忘）

  1. meta-webkit 要用 scarthgap 分支 —— master 只兼容 wrynose，解析直接失败
  2. deb 闭包收包要过 debian 改名映射（cairo→libcairo2），pkgdata 的 PKG: 字段是钥匙
  3. dpkg 账实不符（库文件在、包名未注册）时 --force-depends 是合理手段
  4. WPE 触屏：range 滑块必须 input+防抖，别依赖 onchange
  5. let x 和 window.x 是两个绑定 —— 这个 JS 基础坑伪装成了"轮询覆盖"
  6. INA3221 只认带 label 的 in1/2/3（总线电压）；in4/5/6 是分流电压，会随负载大摆
  7. All Call 0x70 / General-Call SWRST 是 PCA9685 的两个免焊接救命通道
