一台能看见人、听得懂话、答得上来、说得出声、屏上有字的本地语音 AI。四个服务全部开机自启，通电约 15 秒即用。

一 · 系统链路

[C920摄像头] ──人走近──▶ NPU人体检测 ──▶ 唤醒 [C920麦克风] ──说话──▶ VAD切句 ──▶ SenseVoice识别 ──▶ 回复分级 ──▶ matcha合成 ──▶ [Razer喇叭] │ │ 事实接地 / Kimi云端 / 本地兜底 [DL7400屏] 可爱脸+字幕

四层回复（逐层失败自动降级）：① 事实类(时间/日期/天气)查真实数据 → ② Kimi 云端 LLM(联网,流式) → ③ 本地 Qwen0.5B(断网兜底) → ④ 规则。

四 · 操作手册

日常使用

  • 走近摄像头 → Astra 主动说"你好，欢迎，有什么可以帮你的吗？"
  • 对着 C920 正常说话（正常音量、面向摄像头）→ 识别 → 回答 → Razer 出声 → DL7400 屏显字幕
  • 时间/日期会查真实数据；其它问题走 Kimi

看实时日志（排查 / 演示）

# 语音对话
journalctl -u astra-voice -f -o cat
# 视觉唤醒（框高%、触发）
journalctl -u vision-wake -f -o cat

启停服务

systemctl restart astra-voice   # 重启（改配置后用）
systemctl stop astra-voice dl-face vision-wake   # 全停

换云端 key / 模型

vi /etc/astra/llm.conf
# DEEPSEEK_API_KEY=<你的key>   ← 通用容器，装任何家的 key
# LLM_MODEL=moonshot-v1-8k     ← 换模型(如 moonshot-v1-32k)
# LLM_URL=https://api.moonshot.ai/v1/chat/completions
systemctl restart astra-voice   # 改完必须重启

验证 key 通不通（不进语音，直接测）：

set -a; . /etc/astra/llm.conf; set +a
python3 /home/voice/astra_llm.py "你好"
# 出中文=通  |  HTTP 401=key无效  |  HTTP 429=额度/频率

调视觉唤醒灵敏度

vi /etc/systemd/system/vision-wake.service
# ExecStart=/bin/sh /usr/bin/vision_wake.sh 45 2
#                                          ↑框高阈值%  ↑持续帧数
# 太难触发→调小(35)；太灵敏→调大(55)
systemctl daemon-reload; systemctl restart vision-wake

存储清理

systemctl start astra-cleanup.service        # 立刻清一次
systemctl list-timers astra-cleanup.timer    # 看下次自动清理

五 · 常见故障

现象原因解法
说话没反应麦克风电平低/没对准面向 C920、正常音量；日志看有没有"[跳过]太轻"
回复没声音Razer 掉线/音量cat /proc/asound/cards 看 Edition；戴上耳机
答非所问/乱码识别糊(音量太低)靠近说清楚，RMS≥0.04 才准
答"没联网查不到天气"正常(事实接地)不让 AI 编；要真天气需接天气 API
云端不通/慢网络或 keypython3 /home/voice/astra_llm.py "你好" 测；断网自动走本地
屏幕没画面/方框DL7400 掉线/字体lsusb|grep 17e9；中文字体 wqy-zenhei
走近不唤醒阈值太高见 4.6 调阈值
万能重启

出问题先试这个：systemctl restart astra-voice dl-face vision-wake
