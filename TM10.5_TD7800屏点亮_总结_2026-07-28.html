TM10.5-TD7800 LVDS 屏点亮总结（显示 + 触摸）

Synaptics SL1680 (dolphin RDK) · 经 LAMTL / Toshiba TC358775 DSI→LVDS 桥 · 2026-07-28
✅ 显示 1280×720@60 全通 ✅ 触摸多点报点全通 ✅ 断电重启自动恢复 9/9

1. 最终链路

SL1680 J208 (MIPI-DSI 4-lane, 522.4Mbps/lane)
   → FPC → LAMTL 转接板 (Toshiba TC358775, DSI→LVDS)
   → LVDS 单链 5 对差分 (OD口/第一链, 457Mbps/对)
   → TM10.5 面板 U4 的 A 口 → TD7800 TDDI → 1280×720@60 玻璃

触摸:  TD7800 → TP I2C 0x2C (TW0, J32.3/5) + ATTN 中断 (J32.12 = porta10)
       → synaptics_tcm2 驱动 → /dev/input/event2 (双指多点, ~120Hz)
SPI:   TD7800 显示寄存器调试口 (U5.1/2/3/4 ↔ J32.23/19/21/24) → /dev/spidev0.0

3. 六层根因（按发现顺序）

#根因症状修复
1base 设备树的 dsi_panel 是树莓派 7 寸屏配置（800×480/1-lane，power-supply 指向物理不存在的 i2c 0x45 芯片）DSI-1 永远 disconnected，SoC 不发流整体替换为 TM10.5 时序节点
2TC358775 上电 LVDS 输出三态，无人写寄存器有 DSI 流也无 LVDS 输出29 条初始化命令（DSI 通用长写）烤进 DTB
3面板 RESX（U5.9）悬空整颗 TD7800 复位：触摸消失 + 屏黑 + SPI 无响应（三症同源）拉高 3.3V（硬件）
4U-Boot 把 SM_SPI2_SDO/SDI 复用成 UART2 流控SPI 收发全 0dts 加 pinmux 节点夺回 spi2
5DSI→LVDS 零带宽余量（DSI 协议开销吃掉有效速率）全屏随机彩色雪花（光栅稳定）Byte_clk 48975→65300（+33%），LVCFG PCLKDIV 3→4
6触摸 INT 的 GPIO10 bank 归属不明无法写中断节点实验法：ATTN 锁低→I2C 排空→释放变高者 = porta10
最隐蔽的第 5 层：把 DSI 输入带宽配成和 LVDS 输出严格相等时，包头/EoTp/LP 开销使有效像素速率低于面板消耗率 → 桥片行缓冲每行欠载 → 活雪花。对照实验（RK3568 原生 LVDS 同线材正常）排除线材。公式：LVDS 像素钟 = DSI 时钟线频率(byteclk×4) ÷ PCLKDIV，DSI 带宽必须留显著余量（厂商例 4.4%，本项目 33%）。

5. 硬件接线定案

电源 / 控制

  • LAMTL VCC1V8_LCM（J1-8）外供 1.8V；TC358_RST / TC358_PWR_EN 必须用 1.8V 电平——接 3.3V 会经 RESX 的 ESD 二极管倒灌把 1.8V 轨抬到 2.38V（实测踩坑）
  • 12V 背光外供；3.3V 从 J208.1（PWR_3V3_CTL）；使能 J208.6（PWR_ON_DSI）→ J1-13
  • 面板 U5.9（RST TFT/RESX）必须拉高 3.3V——悬空 = 整颗 TD7800 复位（头号坑）

LVDS 数据（LAMTL J3 OD 口 → 面板 U4 A 口，单链走第一链）

LAMTL J3信号面板 U4信号
7 / 8OD0− / OD0+18 / 19LVD0A− / LVD0A+
9 / 10OD1− / OD1+21 / 22LVD1A− / LVD1A+
11 / 12OD2− / OD2+24 / 25LVD2A− / LVD2A+
15 / 16ODCK− / ODCK+（时钟）27 / 28LVDCLKA− / LVDCLKA+
17 / 18OD3− / OD3+30 / 31LVD3A− / LVD3A+

ED 组 / 面板 B 口全不接；GND 多根共地。

触摸 + SPI（J32 排针）

功能接线
触摸 I2CSCL→J32.5、SDA→J32.3、GND→J32.9（总线 TW0，地址 0x2C）
触摸中断TP_INT→J32.12（= SoC porta 线 10）
SPI 调试SCK→J32.23、MOSI→J32.19、MISO→J32.21、CS→J32.24 ↔ 面板 U5.1/2/3/4

6. 调试工具箱（可复用）

工具用法
SPI 直控面板/dev/spidev0.0，9-bit DCX 帧。BIST 开：B0←00, D6←00, DE←01；关：DE←00；读器件码 0xBF 应回 02 3C 68 0A；可读 B1h/C0h 等面板 NVM 配置
触摸报点evtest /dev/input/event2（0-1279×0-719、双指、~120Hz）；可视化：weston-simple-touch
展示横幅gst-launch textoverlay + clockoverlay（标题+走秒时钟）；⚠️ text 属性里不能放换行，多行用多个 textoverlay
重建烧录改 dts → bitbake linux-syna -C compile + -c deploy -f（75 秒）→ DTB 字节级验证 → scp → 板上 dd 双槽 + python 回读校验 → reboot（全程约 4 分钟）
