1. 控制通道：怎么"够得着"这颗芯片

  • 走 DSI 链路本身（通用长写包，类型 0x29），不用 I2C——LAMTL 的 I2C 脚（J1.9/10，1.8V 域）全程未接
  • 命令烤在 dolphin-rdk.dts 的 dsi_panel/command 属性里，VPP 显示固件在每次 modeset 时以 LP 模式自动下发（dpi_lp_cmd=1）
  • 字节格式：0x29 <payload长度> <寄存器地址LE16> <数据LE32>；延时：0xFF <微秒LE32>
  • 机制出处：BSP 自带 dolphin-ws-panel-overlay.dtbo（树莓派屏内置 TC358762，同一手法）
  • 上电默认（datasheet 原文）："All of the LVDS outputs are tri-stated"——不初始化必黑屏，板上无 MCU/EEPROM 代劳

LVCFG 字段（datasheet §6.8.1，0x049C）

位字段含义本项目
11:10PCLKSEL像素钟源：00=DSI 时钟线频率，01=/2，10=/400
7:4PCLKDIVDCLK→PCLK 分频（1=÷1 … 15=÷15，0=÷16）4
1LVDLINK0=单链 1=双链0
0LVENLVDS 发射使能（0=三态）1
时钟公式（本项目最重要的一条知识）
LVDS 像素钟 = DSI 时钟线频率 ÷ PCLKDIV = (Byte_clk × 4) ÷ PCLKDIV
首版（雪花）：48975kHz×4÷3 = 65.3MHz，带宽余量 0% ← DSI 包头/EoTp 开销吃穿 → 行缓冲每行欠载
终版（正常）：65300kHz×4÷4 = 65.3MHz，带宽余量 +33% ← 像素钟分毫不变，只是 DSI 跑快了
带宽账：需求 1567.2Mbps；首版链路 391.8×4=1567.2；终版 522.4×4=2089.6。厂商 XLS 示例自带 4.4% 余量，照抄时序时把余量抄丢了是最隐蔽的坑。

4.3 屏仍黑：硬件层读数

【RESX 悬空，三症同源】BIST 无图案 + 触摸 0x2c 不在 + SPI 全静默
→ U5.9 接高 3.3V 后：i2cdetect 出 2c；SPI ★命中器件码 02 3C 68 0A；BIST 图案点亮

【1.8V 倒灌，万用表实测】VCC1V8_LCM 标称 1.8V 实测 2.38V；I2C 脚同 2.38V
根因：TC358_RST/PWR_EN 接了 3.3V → 经 RESX 的 ESD 二极管倒灌抬轨（2.38 ≈ 3.3 − 两个结压降）
datasheet："LVDS PHY: 1.8 V" → 2.38V = +32% 超标。改 1.8V 电平后恢复。

4.4 SPI 调试通道自身的报错链

① python3: ModuleNotFoundError: No module named 'fcntl'   → ctypes 直调 libc ioctl
② 位敲候选 GPIO "export OK 但写 0 读回 1"                  → 猜的编号没落在 J32 实际脚
③ spidev 首测 mode0/mode3 RX 全 000                        → 数据脚不在 SPI 功能态
④ devmem 0xf7fe2c14 = 0x00095A01
   SM_SPI2_SDO func=2（uart2 RTSn！）SDI func=2（uart2 CTSn！）← U-Boot 占用实锤
⑤ 改 0x00005A01 后 RX 全 1FF                               → 线活了（上拉可见），芯片仍复位
⑥ RESX 接高后 RX = 1FF 17E 008 1E3 080 140 …
   ★ 命中 02 3C 68 0A（stride=8, off=1）← SDO 半拍相位差，解析做位偏移容错

4.5 雪花期（第 5 层根因）症状

全屏随机彩色噪点（evidence/f1.jpg f3.jpg）
 · 光栅几何稳定 → 时钟对锁定、DE 正常
 · 噪点逐帧变化（"活的"）→ 非确定性误码
 · FAIL_DET 未触发自跑黑屏 → 链路层合法，坏的只是数据位
对照实验：RK3568 原生 LVDS + 同一把杜邦线正常 → 排除线材
面板 NVM 实测：B1h = 06 00 5A 00 61 00 10（VESA/24bit4lane/DE+SYNC，porch 90/97/16 全一致）
             C0h = 01 0F 0A 02 D0 00 0A（RTN=271，NL=720 行数实锤）
→ 配置全对 + 链路锁定 + 数据误码 = 行缓冲欠载 → LVCFG 0x31→0x41 + Byte_clk 65300 → 桌面即净

5. 排错决策树

屏全黑
 ├─ DSI-1 disconnected?          → SoC 侧 dsi_panel 节点/驱动（查活动设备树）
 ├─ DSI-1 connected 仍黑
 │   ├─ BIST 能亮?（SPI: B0←00,D6←00,DE←01）
 │   │   ├─ 能 → 面板无罪 → 查桥片：初始化到没到（weston restart 重发）、
 │   │   │        LVPHY/LVCFG、LVDS 线序（OD 组→A 口、P/N）
 │   │   └─ 不能 → 面板侧：RESX(U5.9)? VCC? SPI 通道本身（读 BFh 验证）
 │   └─ 触摸 0x2C 在不在 = 面板整颗死活的免拆快检
 ├─ 全屏活雪花（光栅稳）        → 带宽余量！查 LVCFG PCLKDIV 与 Byte_clk 比值
 ├─ 颜色错/灰阶异常（几何正常）  → VESA↔JEIDA：删 7 条 LVMX 回 JEIDA 默认，或对照面板 B1h.LVFMT
 └─ 画面滚动/撕裂               → HTIM/VTIM 与面板 C0h/B1h porch 对不上
