## 关键结论（详见 docs/ 里的文档）

- J32 的 I²C 已在板内过 **TXB0108**（1.8V↔3.3V），排针侧是 **3.3V 域**，PCA9685 用 3.3V 供电直接可接，**不需要额外电平转换**
- 而 J32 的 **GPIO36/37/38/39 是裸 1.8V**（没过转换）—— 这正是 7-28 TD7800 复位脚踩坑的根源
- **地址冲突**：PCA9685 默认 `0x40` 被板载两颗 INA3221 占用（`0x40`/`0x41`）。用 All Call `0x70` 免焊接，或短接模块 `A1` → `0x42`
- 内核 `CONFIG_PWM_PCA9685` 未开（源码在树里），本方案走**用户态** `/dev/i2c-0`，不重编不重启
- 舵机 **V+ 必须外部供电**；PCA9685 的 **VCC 只能接 3.3V**（接 5V 会经模块上拉灌进 TXB0108 的 3.3V 侧）
