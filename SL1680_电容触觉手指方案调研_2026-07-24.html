三 · 手指传感器 + 皮肤的结构设计

3.1 层叠结构（照 iCub 指尖 + ClearForce 原理拼装）

┌─ 可选：导电外层（碳黑硅胶/导电织物）= 屏蔽 + force 参考电极 ├─ 硅胶"皮肤" 1~3mm（Ecoflex/Dragon Skin/硅胶泡棉） │ = 保护 + 摩擦面 + 【可压缩介电层】← force 的来源 ├─ FPC 柔性电极阵列（互电容矩阵，间距 2~4mm） │ 卷贴在指尖曲面上（S3908 类 IC 本就为柔性屏设计） ├─ 3D 打印指尖内芯（刚性支撑，兼走线通道） └─ Touch IC 就近放指根/掌部，I2C/SPI 出数

3.2 力感应的三条实现路（按上手难度排序）

路线原理硬件改动精度
① 伪力：接触面积+信号强度软皮肤越压越扁 → 接触斑变大、耦合变强；IC 本来就报 ABS_MT_TOUCH_MAJOR/ABS_MT_PRESSURE零——现成模块开箱即得定性～半定量，抓取控制够用
② 真力：压缩介电层（ClearForce 式）皮肤下电极对参考层的距离随力压缩 → 基线电容涨幅 ∝ 力层叠加导电参考层；需 IC 支持力通道（ForcePad/S788x 原生支持）定量（ForcePad 标称到 1000 g）
③ 混合三段：接近→接触→力hover 自电容（没碰到）→ 互电容触点（碰到了）→ 力通道（多用力）同②抓取全流程状态机
抓取控制其实①就够：舵机闭合 → 触点出现停止逼近 → 面积/信号达阈值即"捏稳"。iCub 用 12 电极的定性压力抓了十几年东西。②是产品化再上的台阶。

3.3 皮肤材料要点（iCub 论文实战配方，详见中文整理）

  • 介电层：硅胶泡棉（iCub 用 Smooth-On Soma Foama 15，约 2mm）——轻触即压缩=低压高灵敏；泡棉气泡压实后变硬=非线性扩量程
  • 外层导电皮：碳黑掺硅胶（iCub：CAF4 硅胶 + Vulcan XC72 碳黑，喷涂）——接地，兼做屏蔽（抗杂散电容）和 force 参考电极
  • 皮肤厚度是灵敏度/量程的旋钮：越薄越灵敏、越厚量程越大
  • 指尖曲率小 → FPC 电极间距 2mm 起步，走线留指背侧
  • ⚠️ 泡棉有迟滞/蠕变（iCub 实测确认）——做控制阈值没问题，做精确力标定要选低迟滞介电或加补偿

五 · SL1680 侧软件路径（全部现成）

Touch IC (I2C, J32 pin3/5) │ 内核: synaptics tcm2 / rmi4 / hid-multitouch —— tcm2 已在镜像里 ▼ /dev/input/eventX ── 触点坐标 / ABS_MT_PRESSURE / TOUCH_MAJOR │ └─► 抓取控制环: 舵机(PCA9685,已购)闭合 → 压力阈值 → 停/保持 ▼ TouchComm raw report 模式（诊断接口，FAE 提供文档） └─► 原始电容 heatmap = 触觉图像 └─► SyNAP NPU 分类（与视觉人体检测同一条推理路径） = "摸出来这是圆柱/边缘/布料" —— 触觉物体识别
  • 事件层：evtest 看 /dev/input/event*；Python 标准库直接读 input 事件结构体（无 pip 依赖）
  • 抓取环与语音集成：astra_llm.py try_device() 加「抓一下/松开/轻一点」分支——与已购 PCA9685A+MG90S 舵机方案拼成闭环：电容皮肤=传感，舵机=执行，语音/视觉=大脑，全在一块 SL1680 上
  • 触觉图像上 NPU：触觉 heatmap 本质是低分辨率图像，与 Case41 官方 SyNAP 视觉推理同一条路径
