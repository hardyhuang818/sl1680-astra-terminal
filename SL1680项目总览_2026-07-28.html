1. 项目一句话

在 Synaptics SL1680（4×Cortex-A73 + NPU）上构建边缘 AI 人机交互终端：本地语音 AI（识别/合成全在板上）+ 两条显示链路（DisplayLink DL7400 USB 多屏 + TC358775 直驱 LVDS 触摸屏）+ 视觉唤醒，全部断电自愈。

测试条件：GitHub 开源 Astra SDK（Yocto scarthgap）+ 借用 SL1680 RDK ×1 与 DL7400 EVK ×1 + 自购外设（C920、显示器 ×4 自有、TM10.5-TD7800 触摸屏、LAMTL 转接板、功放喇叭等）。

3C. TD7800 LVDS 触摸屏直驱（v2.7 新增）

#根因修复
1base 设备树是树莓派屏残留dsi_panel 换 TM10.5 时序
2TC358775 上电三态无人初始化29 条 DSI 长写序列烤入 DTB
3面板 RESX 悬空（整颗 TDDI 复位）硬件拉高 3.3V
4U-Boot 占 SPI 数据脚为 UART2 流控dts pinmux 夺回（顺带得 SPI 调试通道）
5DSI→LVDS 零带宽余量 → 活雪花Byte_clk 65300 + PCLKDIV=4（+33% 余量）
6触摸 INT bank 归属不明实验法定位 porta10

配套：SPI 调试工具（读器件码/BIST/读 NVM）、触摸 120Hz 多点、180° 翻转+触摸校准、上海时区。断电自愈 9/9 实测。

4. 关键知识沉淀（跨项目可复用）

  1. DSI→LVDS 桥必须留带宽余量：LVDS 像素钟 = DSI 时钟线频率 ÷ PCLKDIV；零余量 = 行缓冲欠载 = 活雪花
  2. TDDI 复位纪律：TP_RST/RESX 一律硬件拉高——悬空全哑，SoC 控会杀显示
  3. 电平域纪律：1.8V 域脚喂 3.3V 会经 ESD 倒灌抬轨（实测 2.38V）
  4. EDID preferred_mode 不可盲信：160Hz 首选模式让 DL7400 永久阻塞，故障跟屏走
  5. ALSA 非 48k 会内核崩溃：astraout 强制重采样是必需品；寻址用 CARD=名字
  6. 智谱 chat 的 web_search 是假的：调独立搜索 API + 接地；搜不到宁可说查不到
  7. Yocto 四类暗坑：FetchContent 硬关（像断网）/ 无 SOVERSION 的 .so 进错包 / :pn- 只在 conf 生效 / 构建全绿≠功能完整
  8. 板子是真相：改完必回灌 + sha256 对账
  9. 远程三律：复杂命令走脚本文件；先查 busybox 缺项；二进制防 BOM
